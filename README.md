# Unity Bootcamp Demo

This project uses upgraded Unity demo "Bootcamp" and makes it possible to build it using Unity 2017.2.0p2 to produce executable binaries on consoles. The project is already buildable and produces useable demo. Some shaders are disabled for now since they won't compile.

## Goals

- [x] Create minimal buildable PoC
- [ ] Fix tons of script warnings just about everywhere
- [ ] Fix incompatible shaders
- [ ] Fix DoF
